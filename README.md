### 🧭 What I do

- 🔄 **Data pipelines (ETL/ELT):** ingesting CSVs, APIs and scraped data, validating it, and loading it into databases.
- 🗄️ **Data modeling and SQL:** designing schemas and writing queries for analytics.
- ☁️ **Cloud and containers:** deploying data workloads on AWS and GCP with Docker.
- ⚙️ **Automation:** scheduling and orchestrating workflows (n8n, scripts, CI).
- 🤖 **Data for AI:** preparing data for ML models and RAG agents.
- 🖥️ **Frontend:** building dashboards and data apps with React, TypeScript and charting libraries (D3, Chart.js).
